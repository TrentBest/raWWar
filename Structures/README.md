# raWWar Structures

This directory is the working structure/building design laboratory.

A structure is a physical capability. Building it does not automatically make the capability operational.

## Keyed structures

Many structures are built with a **key** describing what they are intended to process, store, train, manufacture or support.

Examples: resource processing plant → specific resource; storage → resource/material/category; barracks → training/qualification program; factory → production family/configuration; research facility → research domain/program.

The key is part of authoritative configuration.

## Re-keying

A structure can be re-keyed rather than demolished and rebuilt.

Candidate rule: re-keying takes **1/4 of the original construction time** and costs **2× the normal construction cost**.

This makes flexible infrastructure valuable while preserving a reason to plan correctly.

## Base-building philosophy

The player should be able to lay out a useful base more easily than a conventional high-micro management game. Complexity belongs in the organization underneath the player's intent, not in forcing the player to hand-place every logistical transaction.
