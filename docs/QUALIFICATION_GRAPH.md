# raWWar — Qualification Graph

Status: Living design model.

> Qualifications are capabilities carried by people.

## Purpose

The Capability Catalogue names qualification families. This document turns them into dependencies that can be resolved by the game.

Qualification desired → prerequisites → training curriculum → instructor/equipment → training capacity → qualified person → readiness → staffable capability.

## Tiers

| Tier | Meaning | Typical authority |
|---|---|---|
| T0 | Unqualified | Observe, assist, or unrestricted basic duties |
| T1 | Basic | Supervised/basic operation |
| T2 | Qualified | Independent ordinary operation |
| T3 | Advanced | Complex/specialized systems |
| T4 | Expert | High-risk/high-value work, diagnosis, certification |
| T5 | Master / Instructor | Teach, certify, develop procedures, rare systems |

Tiers are relative to a qualification family. A T3 pilot is not interchangeable with a T3 materials technician.

## Qualification graph

The general ladder is:

T0 → T1 → T2 → T3 → T4 → T5

Real capabilities branch.

Basic Soldier → Basic Weapons → Heavy / Specialist / Precision / Energy / Plasma / Explosive / Anti-Armor / Anti-Air.

Vehicle Operator → Ground Vehicle → Armored Crew → Driver / Gunner / Commander.

Vehicle Operator → VTOL Crew → VTOL Pilot.

Technical Foundation → Mechanics / Electronics / Power / Sensors / Communications / Armor / Structural / Propulsion.

Research Assistant → Laboratory Technician → Experimental Operator → Researcher → Senior Researcher → Principal Researcher.

Supply Handler → Warehouse Operator → Logistics Specialist → Fleet Logistics / Supply Planner / Strategic Logistics.

## Construction progression

Basic Construction → Structural Construction → Heavy Construction → Underground / Fortification / Industrial / Utilities → Advanced Materials Construction → Aerospace Construction → Orbital Construction.

A structure may require several branches simultaneously.

## Factory progression

General Factory Operator → Assembly Technician → Heavy Fabrication / Precision Fabrication / Electronics / Sensors / Armor / Weapons / Vehicle / Aerospace / Propulsion / Robotics.

Production Engineering, Quality Assurance, Factory Maintenance, and Factory Management are cross-cutting qualifications.

## Qualification is not availability

A person can be qualified and still be unavailable because they are assigned elsewhere, injured, exhausted, training, operating another capability, or missing required equipment.

Qualified + Ready/Available = Staffable.

## Training capacity

A standard barracks contains four VR training modules and trains one four-person squad at a time.

Training therefore consumes physical capacity. Advanced capability may require multiple squads, which creates a real bottleneck in the base.

T5 can become an organizational multiplier if master-level personnel can instruct or certify others.

## Open illumination

Exact tier durations, instructor ratios, failure/recovery, qualification decay, rank relationships, certification authority, squad leadership structure, and faction-specific doctrine remain deliberately unresolved.

Do not invent those values merely to fill a spreadsheet.
